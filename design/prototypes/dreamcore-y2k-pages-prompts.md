Mode: built-in imagegen  
Use case: `ui-mockup`

## Shared visual system

Create high-fidelity 16:9 desktop page prototypes for Elodie Wu's personal developer portfolio. Use the approved Dreamcore + Y2K homepage as the strict visual reference. Combine warm ivory sunlight, faded sage grass, pastel flowers, floating translucent orange-and-white goldfish, hazy conservatory windows and nostalgic camcorder softness with restrained early-2000s UI: translucent aqua glass, pearly chrome edges, pale lavender gradients, tiny pixel icons and readable dark-teal pixel/monospace text. Keep the EW logo at top left and WORK / PLAY / LOGS / ABOUT capsule navigation at top right, highlighting the current page. The result must look like a practical React website rather than standalone concept art. Avoid cyberpunk bars, dark neon cities, browser chrome, phone frames, watermarks and fish covering text.
