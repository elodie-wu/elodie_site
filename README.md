# ElodieWu

My personal website, built with React, TypeScript, Vite, Tailwind CSS, and AI agents.

This site is a place for my portfolio, experiments, notes, and a small cyberpunk puzzle game called **Shell Stack**.

## Current Features

- Cyberpunk tavern-style homepage
- Work / Play / About sections
- Shell Stack puzzle game
- Local best score storage
- Static frontend deployment

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Motion for React
- localStorage

## Future Work

- Add a Logs section for website update history
