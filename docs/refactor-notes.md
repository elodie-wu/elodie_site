# 前端架构重构记录

## 目标和范围

将现有个人网站整理成可以逐步学习 React、复用组件和扩展功能的项目，保持当前页面外观与行为。不新增后端，不修改域名 DNS，不自动提交或推送 Git。

## 已调整

- `app/` 管理路由、公共布局与滚轮切页；Header 和背景音保持在公共布局中。
- `config/site.ts` 集中路由顺序、导航、背景图、音频和社交链接。
- `pages/` 按页面分目录，文案列表与 JSX 分离。
- `components/scene/` 抽出全屏场景和占位玻璃框；`components/ui/` 放通用外链与标题。
- Snake 拆分为视图、React hook、纯算法、类型、配置和内存会话。
- 全局只保留字体、设计变量、浏览器基础样式；页面和功能导入自己的 CSS。
- 首页装饰特效与首页排版分离，保留实际使用的响应式和动画。
- 清除没有引用的旧展示组件及约 251 组无用选择器；旧积木游戏和替换后的美术资源归档到 `legacy/`。
- 移除未使用的 Tailwind 插件与依赖，不引入新的状态或样式库。
- 增加导航、资源路径和 Snake 算法测试，保留旧积木游戏测试。
- 增加类型、静态架构检查与统一 `pnpm check`，自动部署先检查再构建。
- README 说明 React 入口链路、分层职责、常见修改位置和新增页面流程。

## 特别保留

- 当前首页亮度 `1.2`、饱和度 `1.08` 和 About 玻璃底色不透明度 `0.1`。
- 当前生成背景、SonyCam Original 字体、导航荧光、滚轮阻力和长页面边界行为。
- Snake 的现有玩法、自动墙边转向、暂停与跨路由恢复行为。
- `/architecture` 页面、GitHub Pages workflow、自定义域名文件、相对 `base: './'` 和旧手动部署命令。

没有把旧项目描述当作已实现的后端功能，也没有为架构创建空 API / store 目录。

## 验证

- TypeScript 严格检查和未使用变量检查。
- 31 个单元测试：15 个归档游戏测试，10 个 Snake 测试，6 个导航与资源路径测试。
- 静态架构检查：无未引用运行源码、缺失导入、循环依赖或运行代码到归档的依赖，配置中的资源存在。
- Vite 生产构建；发布 CSS 从约 85 KB 缩减到约 34 KB（gzip 前的构建文件大小，当前 gzip 后约 8 KB）。
- 浏览器检查桌面各场景、移动端 About / Play、游戏开始与暂停，以及切页后的棋盘恢复。

自动检查不等于全面浏览器回归测试；以后改交互和样式仍应人工预览。
